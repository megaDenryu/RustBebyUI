# UI・操作・スクリプティング全体仕様

## 1. ウィンドウ一覧

### 1.1 実装済み
| タブ名 | 種別 | 説明 |
|---|---|---|
| World | 3Dビュー | 立方体ボクセルワールド探索 |
| Tetra | 3Dビュー | 四面体ボクセルワールド探索 |
| Calendar | 情報UI | キャラクターの予定表 |
| Messages | 情報UI | 受信メッセージ (チャット風) |
| Documents | 情報UI | 発見した文書閲覧 |

### 1.2 追加予定
| タブ名 | 種別 | 説明 | 優先度 |
|---|---|---|---|
| Map | 情報UI | 島の地図。探索済み場所・イベント地点マーカー | 高 |
| Profiles | 情報UI | 出会った人物のファイル (名前・説明・関係メモ) | 高 |
| Timeline | 情報UI | 起きた出来事を時系列で自動記録 | 中 |
| Photos | 情報UI | 発見した写真・証拠画像 | 中 |
| Browser | 情報UI | ゲーム内偽サイト閲覧 (将来: 実HTTPサーバー連携) | 低 |
| Terminal | 操作UI | コマンド入力・ゲームログ | 低 |
| Radio | 情報UI | 島内放送・天気予報・伏線情報 | 低 |
| Inventory | 情報UI | 所持品 (鍵・道具等) | 中 |

## 4. 操作体系

### 4.1 移動 (既存)
| キー | 操作 |
|---|---|
| W/A/S/D | 移動 |
| Space | ジャンプ/浮上 |
| Shift | ダッシュ/潜水 |
| Q/E | 飛行モード |
| R | 位置リセット |
| 右ドラッグ | カメラ回転 |

### 4.2 UI切替 (新規)
| キー | 操作 |
|---|---|
| 1 | World タブ |
| 2 | Tetra タブ |
| 3 | Calendar タブ |
| 4 | Messages タブ |
| 5 | Documents タブ |
| 6〜0 | 追加ウィンドウ (Map, Profiles 等) |

### 4.3 ゲーム進行 (新規)
| キー | 操作 |
|---|---|
| T | 時間帯を進める (朝→昼→夕→夜→翌朝) |
| N | 翌日まで進める (睡眠) |

### 4.4 インタラクション (新規)
| キー | 操作 |
|---|---|
| F / 左クリック | 調べる (照準先のオブジェクト) |
| Enter | 会話送り / 選択肢決定 |
| ↑/↓ | 選択肢カーソル移動 |
| Esc | 会話/選択肢キャンセル |

## 5. スクリプティング命令 (イベント効果)

### 5.1 実装済み
| 命令 | 説明 |
|---|---|
| `フラグ設定(名前)` | フラグをONにする |
| `フラグ解除(名前)` | フラグをOFFにする |
| `カウンター加算(名前, 値)` | カウンターを加算 |
| `通知(テキスト)` | 画面に通知を表示 |
| `ドキュメント追加{タイトル, 本文, カテゴリ}` | 文書をDocumentsに追加 |
| `メッセージ追加{送信者, 本文}` | メッセージをMessagesに追加 |
| `カレンダー追記{日付, 内容, 重要}` | カレンダーに予定追加 |

### 5.2 追加予定
| 命令 | 説明 | 優先度 |
|---|---|---|
| `選択肢表示{選択肢群}` | プレイヤーに選択させる。各選択肢にフラグ効果を紐付け | 高 |
| `会話開始{台詞群}` | NPCとの台詞を順に表示 (クリック/Enter送り) | 高 |
| `クエスト追加{名前, 説明}` | サイドバーの目標を追加 | 高 |
| `クエスト完了(名前)` | 目標を達成状態にする | 高 |
| `人物追加{名前, 説明}` | Profiles に人物登録 | 高 |
| `タイムライン追記(テキスト)` | 日時付きで自動記録 | 中 |
| `地図マーカー追加{座標, 名前}` | Map に印を付ける | 中 |
| `写真追加{タイトル, 説明}` | Photos に画像追加 | 中 |
| `エリア定義{座標, 半径, 名前}` | 場所に入ると地名表示 | 高 |
| `天候変更(種別)` | 雨/曇り等 (演出+条件分岐用) | 低 |
| `タブ強制切替(ビュー)` | 重要発見時に自動でタブ切替 | 高 |
| `インベントリ追加{名前, 説明}` | アイテム入手 | 中 |
| `ワールド変更{座標, ボクセル種別}` | ボクセルの動的変更 | 中 |
| `プレイヤー移動{座標}` | 強制テレポート | 低 |
| `画面演出(種別)` | 暗転、フラッシュ等 | 低 |
| `BGM変更(トラック名)` | 音楽切替 | 低 |
| `SE再生(名前)` | 効果音再生 | 低 |
| `カメラ演出{方向, 時間}` | 視点を一時的に固定 | 低 |
| `エンディング(種別)` | ゲーム終了演出 | 低 |

### 5.3 条件 (イベント発火条件)

#### 実装済み
| 条件 | 説明 |
|---|---|
| `日付当日(日付)` | 特定の日付と一致 |
| `日付以降(日付)` | 特定の日付以降 |
| `時間帯一致(時間帯)` | 朝/昼/夕/夜 |
| `場所範囲{座標, 半径}` | プレイヤーが範囲内 |
| `フラグオン(名前)` | フラグがON |
| `フラグオフ(名前)` | フラグがOFF |
| `カウンター以上(名前, 値)` | カウンターが値以上 |

#### 追加予定
| 条件 | 説明 | 優先度 |
|---|---|---|
| `エリア内(名前)` | 名前付きエリアにいる | 高 |
| `アイテム所持(名前)` | 特定アイテムを持っている | 中 |
| `天候一致(種別)` | 現在の天候と一致 | 低 |
| `ランダム(確率)` | 確率で発火 | 低 |

## 6. 実装ロードマップ

### Phase 1 (今回)
- ストーリーエンジンにイベント効果を全種追加 (データ構造のみ)
- 操作実装: T/N (時間進行), 数字キー (タブ切替)
- エリア定義 + 地名表示
- 選択肢システム

### Phase 2
- Map ウィンドウ
- Profiles ウィンドウ
- Timeline ウィンドウ
- Inventory ウィンドウ
- クエスト (サイドバー)

### Phase 3
- 会話システム (台詞送り)
- ワールド内調査可能オブジェクト (F キー)
- 天候システム
- ストーリーコンテンツの本格投入

### Phase 4
- Browser ウィンドウ + 組み込みHTTPサーバー
- 画面演出
- BGM/SE
- エンディング分岐
