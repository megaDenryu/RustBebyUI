# ゲーム設計書: Cyber Studio -- マイクラ in VSCode ADV

## 1. コンセプト

ボクセルワールドを歩き回りながら、VSCode風マルチウィンドウUIで情報を集め、
島の因習に巻き込まれた人物を救う（あるいは真相を暴く）アドベンチャーゲーム。

『人のカレンダー』のように現実のWebを探索するARGではなく、
**3Dボクセル空間とゲーム内ウィンドウの両方が調査フィールド**になる。

### 体験の核
1. ボクセルワールドを探索 -> 物理的な手がかりを発見
2. ウィンドウ（カレンダー、メッセージ、ドキュメント等）で情報を読み解く
3. 空間 x 時間 x 情報の組み合わせで謎を解く
4. 選択によってストーリーが分岐する

### タイトル
- "One O Net - Cyber Studio v0.9"

## 2. ストーリーエンジン仕様

### 2.1 設計思想: 宣言的ストーリー定義

ストーリーは **Rustの構造体として宣言的に定義** する。
手続き的なスクリプトではなく、データとしてイベントや条件を記述し、
エンジンが毎フレーム評価・発火する。

```rust
// ストーリー定義の例 (Rustコード上で宣言的に書く)
pub fn 第一章イベント群() -> Vec<ストーリーイベント> {
    vec![
        ストーリーイベント {
            識別子: "手紙の発見".into(),
            条件群: vec![
                イベント条件::日付以降(ゲーム日付 { 月: 4, 日: 5 }),
                イベント条件::場所範囲 { 座標: Vec3::new(15.0, 6.0, 20.0), 半径: 3.0 },
            ],
            効果群: vec![
                イベント効果::ドキュメント追加 {
                    タイトル: "古い手紙".into(),
                    本文: "差出人不明の手紙...".into(),
                    カテゴリ: ドキュメントカテゴリ::手紙,
                },
                イベント効果::通知("足元に古い手紙が落ちている...".into()),
                イベント効果::フラグ設定("手紙発見済み".into()),
            ],
            一度きり: true,
        },
    ]
}
```

### 2.2 コアデータ構造

```
ストーリーエンジン (Resource)
├── イベント群: Vec<ストーリーイベント>  -- 全イベント定義
├── 発火済み: HashSet<String>          -- 発火済みイベントID
└── 評価ループ: 毎フレーム条件チェック -> 発火

ゲーム時間 (Resource)
├── 現在日付: ゲーム日付 (月, 日)
├── 現在時間帯: 時間帯 (朝/昼/夕/夜)
└── 経過日数: u32

フラグストア (Resource)
├── フラグ: HashMap<String, bool>     -- ON/OFFフラグ
└── カウンター: HashMap<String, i32>  -- 数値カウンター

ドキュメントストア (Resource)
├── Vec<ドキュメント>                 -- タイトル/本文/カテゴリ/既読
└── カテゴリ: 手紙/日記/地図/公文書/メモ

メッセージストア (Resource)
├── Vec<メッセージ>                   -- 送信者/本文/日付/既読
└── 未読管理

カレンダーストア (Resource)
└── HashMap<ゲーム日付, Vec<カレンダー予定>> -- 日付->予定(内容/重要フラグ)

通知ストア (Resource)
└── Vec<ゲーム通知>                   -- テキスト/残り秒数

クエストストア (Resource)
└── Vec<クエスト>                     -- 名前/説明/完了

人物ストア (Resource)
└── Vec<人物>                         -- 名前/説明

タイムラインストア (Resource)
└── Vec<タイムラインエントリ>          -- 日付/時間帯/テキスト

エリアストア (Resource)
├── エリア群: Vec<エリア定義>          -- 名前/座標/半径
└── 現在エリア: Option<String>

選択肢ストア (Resource)
├── 選択肢群: Vec<選択肢項目>         -- テキスト/効果群
├── カーソル位置: usize
└── 決定済み効果: Option<Vec<イベント効果>>

天候ストア (Resource)
└── 現在の天候: 天候種別 (晴れ/曇り/雨/嵐/霧)

会話ストア (Resource)
├── 台詞群: Vec<台詞>                -- 話者/本文
└── 現在位置: usize

調査ポイントストア (Resource)
└── Vec<調査ポイント>                 -- 名前/座標/半径/効果群/使用済み

ヘルプ表示 (Resource)
└── 表示中: bool
```

### 2.3 イベント効果の種類

#### 実装済み

| 効果 | 説明 |
|---|---|
| `フラグ設定(名前)` | フラグをONにする |
| `フラグ解除(名前)` | フラグをOFFにする |
| `カウンター加算(名前, 値)` | カウンターに値を加算 |
| `通知(テキスト)` | 画面に通知を表示 |
| `ドキュメント追加{タイトル, 本文, カテゴリ}` | ドキュメントウィンドウに文書追加 |
| `メッセージ追加{送信者, 本文}` | メッセージウィンドウに受信 |
| `カレンダー追記{日付, 内容, 重要}` | カレンダーに予定追加 |
| `クエスト追加{名前, 説明}` | クエストを追加 |
| `クエスト完了(名前)` | クエストを完了にする |
| `人物追加{名前, 説明}` | 人物一覧に追加 |
| `タイムライン追記(テキスト)` | タイムラインにイベント記録 |
| `エリア登録{名前, 座標, 半径}` | 新しいエリアを登録 |
| `地図マーカー追加{座標, 名前}` | マップにマーカー追加 (小半径エリアとして登録) |
| `タブ切替(タブ名)` | 指定タブをアクティブにする |
| `選択肢表示{タイトル, 選択肢群}` | プレイヤーに選択を提示 |
| `天候変更(天候種別)` | 天候を変更 (フォグ色・環境光も連動) |
| `会話開始(台詞群)` | NPC会話を開始 (Enter/Space送り) |
| `調査ポイント登録{名前, 座標, 半径, 効果群}` | 調査可能オブジェクトを配置 |

#### 将来実装予定

| 効果 | 説明 |
|---|---|
| `ワールド変更{...}` | ボクセルの設置/破壊、オブジェクト出現 |
| `BGM変更(トラック名)` | 音楽切替 |
| `SE再生(名前)` | 効果音再生 |
| `画面演出(種別)` | 画面フラッシュ、暗転など |
| `プレイヤー移動(座標)` | プレイヤーを指定座標に移動 |
| `カメラ演出{...}` | カメラワーク演出 |

### 2.4 条件の種類

#### 実装済み

| 条件 | 説明 |
|---|---|
| `日付当日(日付)` | 指定日と一致 |
| `日付以降(日付)` | 指定日以降 |
| `時間帯一致(時間帯)` | 指定の時間帯 (朝/昼/夕/夜) |
| `場所範囲{座標, 半径}` | プレイヤーが指定座標の半径内 |
| `エリア内(名前)` | プレイヤーが指定エリア内 |
| `フラグオン(名前)` | 指定フラグがON |
| `フラグオフ(名前)` | 指定フラグがOFF |
| `カウンター以上(名前, 値)` | カウンターが指定値以上 |
| `天候一致(天候種別)` | 現在の天候が一致 |
| `アイテム所持(名前)` | `アイテム_{名前}` フラグがONか判定 |

条件群は AND 連結 (全条件を満たしたときに発火)。

#### 将来実装予定

| 条件 | 説明 |
|---|---|
| `ランダム(確率)` | 指定確率で発火 |

## 3. マルチウィンドウUI仕様

### 3.1 ウィンドウ一覧 (タブ)

VSCode風のタブで切り替え可能なウィンドウ群 (キー 1-9 で切替):

| タブ名 | キー | 種別 | 説明 | 状態 |
|---|---|---|---|---|
| **World** | 1 | 3Dビュー | 立方体ボクセルワールド探索 | 実装済み |
| **Tetra** | 2 | 3Dビュー | 四面体ボクセルワールド探索 | 実装済み |
| **Calendar** | 3 | 情報UI | 日付ごとの予定表示 | 実装済み |
| **Messages** | 4 | 情報UI | 受信メッセージ一覧 (未読バッジ付き) | 実装済み |
| **Documents** | 5 | 情報UI | 発見済み文書閲覧 (カテゴリ付き/未読バッジ付き) | 実装済み |
| **Map** | 6 | 情報UI | 登録済みエリア一覧 | 実装済み |
| **Profiles** | 7 | 情報UI | 人物一覧 | 実装済み |
| **Timeline** | 8 | 情報UI | イベント時系列表示 | 実装済み |
| **Inventory** | 9 | 情報UI | アイテム一覧 (フラグベース) | 実装済み |
| **Photos** | - | 情報UI | 写真閲覧 | 未実装 |
| **Browser** | - | 情報UI | ゲーム内偽サイト | 未実装 (将来) |
| **Terminal** | - | 操作UI | コマンド入力・ゲームログ | 未実装 (将来) |
| **Radio** | - | 情報UI | ラジオ放送 | 未実装 (将来) |

### 3.2 サイドバー

ファイルツリーの代わりに調査の進捗を表示:
- 手がかり一覧 (発見済みフラグのリスト)
- クエスト一覧 (進行中/完了)
- 未読バッジ (Messages(N), Docs(M))
- 統計情報 (Documents数, Messages数)

### 3.3 ステータスバー

- 日付・時間帯 (`4月5日 [夕] Day 5` 形式)
- 現在エリア名
- 天候表示 (晴れ/曇り/雨/嵐/霧)
- 未読カウント
- FPS

### 3.4 オーバーレイUI

- **選択肢**: 選択肢項目を表示、上下キーで選択、Enterで決定、Escでキャンセル
- **会話**: 台詞を1行ずつ表示、Enter/Spaceで送り、Escでスキップ
- **ヘルプ**: H キーで操作一覧のオーバーレイ表示
- **通知**: 画面に一時テキスト表示 (自動消滅)

## 5. 環境演出

### 5.1 天候ビジュアル

天候種別に応じてフォグ色と環境光明度を動的変更:

| 天候 | フォグ色 | 視界距離 |
|---|---|---|
| 晴れ | 青空 | 800 |
| 曇り | 灰色 | 400 |
| 雨 | 暗灰色 | 250 |
| 嵐 | 暗色 | 120 |
| 霧 | 白灰色 | 350 |

### 5.2 昼夜サイクル

時間帯に応じて太陽光の色・角度・照度を変更:
- 朝: 朝日色、低角度
- 昼: 白色、高角度、最大照度
- 夕: 夕焼け色、低角度
- 夜: 月明かり色、最低照度

## 6. セーブ/ロード

- **F5**: JSONファイルにゲーム状態を保存
- **F9**: JSONファイルからゲーム状態を復元
- 保存対象: ゲーム時間、プレイヤー位置、フラグ/カウンター、発火済みイベント、全ストアのデータ
- 本体型に直接 Serialize/Deserialize を実装 (変換用構造体を介さない)

## 7. ワールドとストーリーの統合

### 7.1 調査可能オブジェクト (実装済み)

ワールド内の特定座標にインタラクト可能な調査ポイントを配置:
- 浜辺の流木 -> こよみのブレスレット発見
- 古い井戸 -> 倉庫の鍵発見
- 大きな木 -> コトミの落書き(1995)
- 祠裏の石 -> コトミの日記断片

Fキーまたは左クリックで周囲の調査ポイントを調べる。一度使用した調査ポイントは再使用不可。

### 7.2 ワールドの時間連動 (将来実装)

ゲーム内日付に応じてワールドが変化:
- 特定の日に新しい建物が出現
- 祭りの日に装飾が追加
- 事件後に道が封鎖される

## 8. 組み込みHTTPサーバー (将来実装)

ゲームのexeが簡易HTTPサーバーとして動作し、
ブラウザで `localhost:PORT` を開くとゲーム内偽サイトにアクセスできる仕組み。

### 用途
- ゲーム内の「島の公式HP」「学校サイト」「個人ブログ」を実際のブラウザで閲覧
- ゲーム進行に応じてサイト内容が動的に変化
- 現実のブラウザとゲーム内ブラウザウィンドウの連動

### 技術方針
- Rustの軽量HTTPサーバー (`axum` or `warp`) をゲームプロセス内で起動
- ストーリーエンジンのフラグストアを参照してページ内容を動的生成
- `open::that("http://localhost:PORT")` でブラウザ自動起動
