# デバッグシステム仕様

## 1. 目的

開発中にゲームの内部状態を可視化・記録し、問題の原因を素早く特定する。
デバッグ機能はリリース時に無効化可能であること。

## 2. デバッグオーバーレイ (F3トグル)

### 2.1 表示項目

F3キーで画面左上にオーバーレイ表示をトグルする。

```
=== DEBUG ===
Pos: (8.00, 17.50, 8.00)
Ground: 15.74
Chunk: (1, 2, 1)
Facing: yaw=-0.40 pitch=-0.10
Mode: Walking | Grounded
Speed: 5.0 | VSpeed: 0.0

Chunks: 142/1200 loaded | 8 pending
Meshes: 89 (53 empty skipped)
Memory: ~12.3 MB voxel data

Weather: Clear | Time: Apr 5 Morning
Area: (none)
Flags: 3 on | Events: 2 fired
```

### 2.2 セクション定義

| セクション | 内容 | 更新頻度 |
|---|---|---|
| プレイヤー状態 | 座標、地形高さ、チャンク座標、向き、移動モード | 毎フレーム |
| チャンク状態 | 読込済み/全体、保留中、空メッシュスキップ数 | 毎フレーム |
| ゲーム状態 | 天候、時間、エリア、フラグ数、発火済みイベント数 | 変更時 |

### 2.3 表示レイアウト

- 位置: 画面左上 (メインUIの上にAbsoluteで重ねる)
- 背景: 半透明黒 (rgba 0,0,0,0.7)
- フォント: ゲームフォント 10px
- 行間: 2px

## 3. コンソールログ

### 3.1 ログレベル

Bevyの標準ログシステム (`info!`, `warn!`, `error!`) を使用。

### 3.2 記録対象

| イベント | レベル | 例 |
|---|---|---|
| チャンク生成完了 | debug | `Chunk (1,2,1) generated: 234 faces, LOD 1` |
| 空チャンクスキップ | debug | `Chunk (1,5,1) skipped: all air` |
| ストーリーイベント発火 | info | `Event fired: "手紙の発見"` |
| セーブ/ロード | info | `Saved to save.json (1.2KB)` |
| エリア遷移 | info | `Area changed: (none) -> 浜辺` |
| 衝突判定失敗 | warn | `Collision check: chunk (1,2,1) not loaded` |
| リソース未初期化 | error | `Resource not found: ゲームフォント` |

## 4. 起動時の安全機構

### 4.1 ワールド読込待機

起動直後、プレイヤー直下のチャンクが読込完了するまで:
- 重力を適用しない (垂直速度 = 0)
- 画面にローディング表示 ("Loading world...")

### 4.2 判定条件

プレイヤー座標から算出したチャンク座標 (cx, cy, cz) と
その直下 (cx, cy-1, cz) の両方が `読込済み` に存在すれば読込完了とみなす。

## 5. パフォーマンス改善 (デバッグで発見した問題)

### 5.1 空チャンクスキップ

メッシュ生成結果が頂点0の場合、Entityを生成せずスキップする。
チャンク管理の `読込済み` にはチャンクデータのみ保持 (Entity不要として記録)。

### 5.2 チャンク読込高速化

| パラメータ | 旧値 | 新値 | 理由 |
|---|---|---|---|
| 毎フレーム最大タスク数 | 2 | 4 | 非同期なのでCPU活用 |
| メッシュ登録上限/フレーム | 1 (break) | 4 | 起動を高速化 |

### 5.3 Y方向の最適化

Y描画距離を3から2に縮小 (7段 -> 5段)。
地形は Y=0~35 なので5段 (cy=-1~3 at ground level) で十分。

## 6. 実装構成

### 新規ファイル
- `src/デバッグ.rs` -- デバッグオーバーレイ + ローディング + ログ

### 変更ファイル
- `src/main.rs` -- モジュール宣言、システム登録
- `src/チャンク管理.rs` -- 空チャンクスキップ、読込高速化、Y描画距離調整
- `src/四面体チャンク管理.rs` -- 同上
- `src/カメラ制御.rs` -- ワールド読込待機
- `src/UI設定.rs` -- デバッグオーバーレイ用コンポーネント

### システム登録

```rust
// Update
デバッグ::デバッグ表示更新,
デバッグ::ワールド読込判定,
```

## 7. 操作

| キー | 動作 |
|---|---|
| F3 | デバッグオーバーレイのトグル |

既存のヘルプ (Hキー) にも F3 の説明を追加。

## 8. ビルド時の制御

`#[cfg(debug_assertions)]` で囲むことで、リリースビルドではデバッグシステムを完全に除外可能にする。
ただし現段階では常に有効。リリース時に対応。
