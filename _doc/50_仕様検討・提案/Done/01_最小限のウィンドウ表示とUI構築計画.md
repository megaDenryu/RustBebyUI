# 実装計画：最小限のウィンドウ表示と UI 構築 (WF-200)

## 1. 目的
Bevy エンジンを使用して Windows 上にウィンドウを表示し、SengenUI のようなメソッドチェーンに近い感触で UI（ボタンとテキスト）を構築する。

## 2. 依存関係の追加 (Cargo.toml)
最新の `bevy` を追加します。

## 3. 実装モジュール構成
- `main.rs`: エントリポイント。App の初期化とプラグイン登録。
- `ui_components.rs`: UI 要素を構築する「View」相当のロジック。
- `systems.rs`: ボタンクリック等のイベントを処理する「Orchestrator」相当のロジック。

## 4. 目標とする UI 構造
- 背景をダークテーマに設定。
- 中央に「Rust + Bevy UI」というテキスト。
- その下に「クリックしてください」というボタン。
- ボタンクリックでテキストが「Hello from Rust!」に変わる。

## 5. 検証手順
1. `cargo check` で静的解析を通す。
2. `cargo run` で実際のウィンドウ表示を確認する。
